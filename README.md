# CRM Frontend Application

## Description
This is the frontend of a CRM web application built using React.
It connects to an already submitted backend API.

## Features Implemented
- User Login & Authentication
- Customer Management (Add, Edit, Delete)
- Case Management (Add, Edit, Close, Delete)
- Search and Filters
- Responsive UI
- Proper confirmation dialogs and error handling

## Technologies Used
- React
- Axios
- CSS
- React Modal

## How to Run
```bash
npm run dev
npm start
